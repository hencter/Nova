# Atomic Notes

> **Status: seedling** — stub note. See [[zettelkasten-methodology|Zettelkasten Methodology]] for full context.

## Core Principle

An atomic note captures **exactly one idea** in a self-contained unit. Formally:

$$
\text{atomic}(N) \iff |\text{ideas}(N)| = 1
$$

## Rules

1. One concept per file
2. Self-contained — understandable without surrounding context
3. Links provide enrichment, not dependency
4. If you can't summarize in 2-3 sentences, split it

## Why Atomicity Matters

- **Precise cross-referencing**: Link to the exact concept
- **Independent updates**: Change one note without merge conflicts
- **Graph clarity**: Each node is a concrete idea
